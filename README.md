# SCE CENTRAL · UAT (DEV)

Frontend ujian penerimaan pengguna (UAT) untuk SCE CENTRAL, Sri Cheras Enterprise.

- Persekitaran **DEV**. Semua data memerlukan log masuk; akaun didaftar oleh pentadbir sistem sahaja.
- Program dan Order Signboard dibaca daripada rekod operasi secara baca sahaja.
- Tugasan disimpan dalam pangkalan data DEV yang berasingan.

Kod sumber penuh, backend dan dokumentasi disimpan dalam repo private.
